## 5. Risks measured on forjar (copy the fixes, not the lessons)

- PR merge commit vs pushed head in CI (`quorum.yml` checks out `head.sha`, `fetch-depth: 0`).
- `QUORUM_BASE` env override was a one-word bypass — the base is a constant.
- Pre-push must read git's ref protocol before anything consumes stdin; the REMOTE ref decides exemption (`git push origin main:feature` bypass); the local sha is kept so a push of branch B from a branch A checkout resolves B's receipt (#400).
- `fail()` inside `$(...)` swallows the verdict — window.sh returns via globals.
- A skill named `dogfood` is shadowed by a user-scope skill — name it `bashrs-dogfood` and pin it with a test.
- Gate E once was prose discharged by an agent — a requirement without an exit code is not a gate.
- Hunk-level citation anchoring failed honest work at 25% — file-level 33% is the tuned floor.
- A truncation heuristic fired on a complete sentence — dropped; exact-budget and unclosed-backtick rules kept.
