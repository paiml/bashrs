# Decisions taken by quorum — v7.2.0 window, 2026-09-11

Every decision below was deferred to the maintainer at some point and is now settled by a blind
three-lane agy quorum. The operator's instruction on 2026-09-11 was to replace the asks with the
quorum's consensus, so a majority of three lanes binds and there is no human tie-break. Where the
orchestrator had recorded a position, the vote is stated against it.

**Method.** Three lanes of agy 1.2.0 in grill-me mode, one identical prompt each, launched from three
empty working directories with every fact inlined. The lanes have no shell and no repository access, so
each answer is reasoning over measured facts supplied in the prompt; every fact in those prompts was
measured by the orchestrator first. Lane output is validated against
`~/.claude/skills/paiml-implement/agy/grillme-schema.json`.

## 6. What this record does not claim

The lanes have no shell and no repository access. Every fact they weighed was measured by the
orchestrator and inlined into their prompt, and each lane's own transcript shows a single step with one
tool call, so `grounding: cited` in a lane file means cited from that prompt, not independently
verified. The decisions are the lanes'; the measurements behind them are the orchestrator's, and each
one is reproducible from the commands recorded in this file and in `docs/audits/crux-7.1.0.md`.
